# TH02 主项目接入预览

`ports/th02` 将 DOSBox-X 封魔录运行时接入主启动器与合作房间。Package Store 提供原版游戏资源，主项目文件服务保存 `HUUHI.DAT` 与 `HUUMA.CFG`；两人、三人房间继续使用原有游戏同步内核与主项目 Relay/WebRTC 传输。

在 monorepo 根目录运行 `node ports/th02/scripts/dev.mjs` 启动本地适配。入口包括单人游戏、独立存档空间和主大厅合作模式；测试脚本列于 [适配说明](../../ports/th02/README.md)。
