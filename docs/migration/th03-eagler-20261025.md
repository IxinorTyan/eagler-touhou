# TH03 主项目接入预览

`ports/th03` 将梦时空 DOSBox-X Runtime 接入主启动器、Package Store 和两人对战房间。主项目负责文件空间、房间成员与开局；原生游戏继续负责角色选择和对战，运行时保留其确定性输入同步与状态校验路径。
