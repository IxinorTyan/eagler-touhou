# TH05 来源子树与主项目适配

`ports/th05` 从 [IxinorTyan/th05-coop-lab](https://github.com/IxinorTyan/th05-coop-lab) 保留完整来源历史并接入适配代码，来源提交为 `6eb46ed1d4f581f109ffa494ea0d21d54c8b38df`。`node ports/th05/scripts/build-eagler.mjs --assets=../th05-coop-lab/web` 生成 Runtime 目录与 `content/th05.data`，逐文件输入哈希和提交记录保存在 `content/source.json`。

普通版和多人版共用主项目 Runtime 协议、资源安装与 IDBFS 文件格式。适配层为模块 Worker 和经典 Worker 安装相同的只读 DATA 资源提供器，经典 DOSBox Worker 保留 `importScripts`；单人原生文件通过生产用文件导出消息同步到主项目存档。普通版与 MP 分别使用 `/savesth05`、`/savesth05mp`，分数与配置文件为 `GENSOU.SCR`、`MIKO.CFG`。

房间成员、角色、难度、准备状态与开局身份由主项目管理。TH05 的 GameQueue、启动 RTT 策略、状态校验与回滚内核保持为同步执行端；主项目 Relay 使用认证来源信封转交游戏消息，底层支持 WebRTC 直连和 Relay 路由。结束时交换全员可靠结束消息与回执，再释放 Worker 和传输，主项目随后重建房间预览。

真实 Chromium 验证覆盖原版单人标题与存档提取、主大厅双人完整开局、主键盘映射移动、原生暂停退出及同房第二局。三人 Relay 回滚测试推进超过 480 个确认帧，验证本地音频资源请求与全员原生退出；生成目录通过 Runtime 依赖闭包检查。主项目录像播放工作台、多人观战及多人局原版分数提取在后续接入范围内。


Runtime 的 `NOTICE.html` 保留 DOSBox-X fast/rollback 核心的 GPL-2.0、NP2 BSD-3-Clause 和 Phosphor Icons MIT 许可证全文与来源说明。

## 来源与维护

原仓库 [`th05-coop-lab`](https://github.com/IxinorTyan/th05-coop-lab) 的 `main` 提交 `6eb46ed1d4f581f109ffa494ea0d21d54c8b38df` 及该分支截至此点的全部 32 个原始提交均保留为当前仓库的祖先；作者、时间、说明与原始提交 ID 均保留。主站适配提交的目录投影与原仓库通过合并连接，当前目录由标准 Git subtree 导出。

首次连接提交为 `785f8b99c7f292ea07e1c83264fcbe25d64ee375`，导出基点为 `5058c1bff6c11ab30419c163a3ecaa7da2e2cc64`。原仓库 README 保存在 [README-UPSTREAM.md](../../ports/th05/README-UPSTREAM.md)。源文件与运行资源的划分记录在 [source-import.json](../../ports/th05/source-import.json)。

在 monorepo 根目录运行 `node ports/th05/scripts/build-eagler.mjs --assets=../th05-coop-lab/web`，从本目录代码和外部资源生成 Runtime 与 DATA。`--source=<完整原仓库>` 保留独立来源对照构建入口。开发脚本默认读取相邻原仓库的资源目录，也可通过 `PC98_ASSETS_DIR` 指定。

历史查询、subtree 导出、后续同步与 PR 合并步骤见 [TH01–TH05 子树维护](pc98-subtree-20261026.md)。
