原版单人

从开头与标题菜单出发。角色、难度和各项设置，都在原作中选择。

开始旅程

原版音源由 PC-98 核心模拟；独立 BGM 使用转换后的原版音乐，音效仍由核心输出。修改语言或音乐输出后，点“重新开始”生效。

触摸持续判定点与移动选项可在“按键与触控”中设置。

等待启动 · 需要新版 Chrome / Edge 浏览器。

触屏可开启触屏操作：单指相对拖动，二指或低速键按住低速，点击开火切换自动射击；菜单使用方向与确认按钮。

原版操作

方向键移动 / 选择
Z 射击 / 确认
X Bomb / 返回
Shift 低速
Enter 确认
Esc 游戏暂停菜单

完整单人流程

保留开头、标题、游戏内选人、难度选择及原版资源规则。主篇与 Extra 由原版菜单进入。

点击画面后使用键盘。页面与触屏暂停键打开游戏原生暂停菜单；菜单选择退出关卡后返回原版标题菜单，可再次开始游戏。切出页面请求原生暂停。

每次重新开始使用初始磁盘，不持久保存进度、高分或游戏内配置。
