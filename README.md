## 启动

需要 Python 3.10 或更新版本，以及新版 Chrome / Edge。单人、本地合作需要浏览器支持 WebAssembly JSPI。通过 HTTP 服务打开页面，不能直接双击 HTML 文件。

| 模式 | 启动方式 | 地址／端口 |
| --- | --- | --- |
| 原版单人 | `start.bat`，首页选择“单机游戏” | `http://127.0.0.1:9866/solo.html` |
| 本地双／三人 | `start.bat`，首页选择“本地多人” | `http://127.0.0.1:9866/local.html` |
| 双／三人局域网 | `start-lan.bat` | 默认 9893，队友使用终端显示的局域网地址 |
| 公网联机 | `start-public.bat` 或部署 `lan_server.py` | 默认 9893，使用可从互联网访问的服务地址 |

命令行也可启动：

```sh
python server.py
python lan_server.py
```

本地服务仅监听本机；手机或平板访问时使用局域网服务。端口被占用时可手动指定，例如 `python server.py --port 9891 --no-browser` 或 `python lan_server.py --port 9894`，以终端显示的地址为准。

WebSocket 中继需要额外安装依赖：

```sh
python -m pip install -r requirements-lan.txt
```

### 局域网加入

1. 房主运行 `start-lan.bat`，所有设备连接同一局域网。
2. 所有人打开房主终端显示的地址，如 `http://192.168.1.20:9893/lan.html?network=lan`。队友不要输入 `127.0.0.1`。
3. 房主创建房间，选择人数、难度、语言、初始残机／Bomb 及回滚开关；队友输入四位房间号加入。
4. 各自选择座位和角色，全员准备后由房主开始。共同设置发生变化时需要重新准备。

### 公网加入

所有人访问同一个已部署的公网网址和房间服务。公网默认 STUN 辅助 WebRTC 直连，连接失败时整房回退到已部署的 WebSocket 中继；也可在大厅“连接方式”中选择始终中继。

`start-public.bat` 使用 `--network public-rtc`，不会自动配置公网 IP、端口映射或隧道。旧 `network=public-ws` 链接保留强制中继行为。HTTPS、反向代理和 STUN／TURN 配置见 [公网部署说明](README-PUBLIC.md)。

## 操作

| 玩家 | 移动 | 射击 | Bomb | 低速 |
| --- | --- | --- | --- | --- |
| 单人／本地 P1 | 方向键 | Z | X | Shift |
| 本地 P2 | W / S / A / D | J | L | K |
| 本地 P3 | T / G / F / H | V | B | N |

联机每台设备只控制自己的座位，使用方向键或 WASD 移动、Z / J 射击、X / L 释放 Bomb、Shift / K 低速。

Esc 或屏幕暂停按钮打开游戏自带的暂停菜单；方向键选择，Z / Enter 确认，Esc 继续。选择退出会关闭模拟器并结束本局。联机任意席可操作共同暂停菜单，退出在输入确认后生效。

触屏支持单指拖动、第二指低速、自动开火开关、Bomb／双击 Bomb、限速／不限速、灵敏度、判定点和横竖屏独立布局。通过屏幕控件调整触屏布局，支持全屏及截图。本地多人可选择触屏操作的席位。

原版单人保留开头、标题菜单、选人和原作规则，仅加入触摸输入及状态接口。合作模式在网页设置人数、角色和难度后直接进入关卡，Extra 直接进入 Extra 关。

## 合作规则

幽香的异色残影已接入：同角色第二次出现为暖色衣服＋蓝紫残影，第三次为紫红衣服＋青蓝残影，第一次保留原版。残影使用预览素材的独立 RGB 显示，三种姿态均生效；服装继续使用原生色阶，射弹使用下述逐弹种 RGB 方案，幽灵保持原方案。本机及联机（含回滚）共用此效果。

- 不同角色使用原色；同一角色按 P1 → P2 → P3 的出现顺序，依次使用原色、备用色一、备用色二。灵梦／魔理沙备用色为蓝、绿，魅魔／幽香为暖色、紫红；幽灵沿用该玩家的配色，救援复活后保持一致。实战主弹、副弹及其命中特效按源帧独立选色，右侧机型标记使用对应主弹颜色；子机及未使用附属图块保持原色。射弹使用审核素材的独立 RGB，服装仍使用 PC-98 原有色阶，保留坐骑原色。
- 每席独立生命、Bomb、Power、分数、高分、点、梦和擦弹统计；Boss 血量与得分按人数调整，双人 ×1.5、三人 ×2.2。Power 拾取补正为双人 ×1.5、三人 ×2。
- Power 归拾取者；Bomb 道具奖励所有存活席位；1UP 给全队加命，并复活已彻底死亡的队友。已确认离线的席位不参与道具奖励和救援。个人分数加命归本人。
- 彻底死亡后显示幽灵，位于存活自机和僚机下方。靠近队友，按住低速并停火 90 游戏帧可转移一条生命；救活幽灵时，救援者 Bomb 减半，被救者得到一个 Bomb。
- Bomb 库存独立，原版世界同一时刻运行一个 Bomb 演出。已修正交替释放时绘制回调改写寄存器导致的资源串用。
- 背景、敌人、弹幕、道具及公共弹池仍按原版世界更新；个人 HUD 显示对应席位资源。

可使用原版模拟音源或浏览器独立 BGM。资源／编译缓存用于加快后续启动，每次开局创建新的模拟器实例；游戏进度、高分和本局内存不持久保存。

启动时并行读取磁盘、编译核心和准备素材；已校验的残影素材也使用资源缓存。游戏初始化期间复用状态签名候选位置，减少对整个模拟器内存的重复扫描。更新后重启服务并刷新页面，使所有客户端使用同一前端构建。

## 联机与性能

当前协议为 `th05-netplay/7`。开局校验房间配置、游戏盘、引擎及前端构建身份，各端必须使用同一版本；更新后重启服务，全员关闭旧页、刷新并重新建房。

断线处理对齐 TH04：连接异常后保留本局并等待 5 秒恢复；无数据超过 3 秒也会进入恢复等待。直连会重新协商数据通道，中继会重建当前玩家的连接，恢复后补齐输入和同步校验。房间状态请求暂时失败时继续保留游戏连接并重试。客机超时后，由房主与其余在线玩家确认共同离线帧，离线角色转为本局永久幽灵，其余玩家继续；房主恢复超时则结束本局。暂停和回滚同样遵守此规则。恢复限于原页面仍保留本局的情况，刷新页面或关闭后重新加入不能接回进行中的游戏。

回滚默认关闭，开启后允许先预测输入，收到真实输入后纠正。直连和中继均使用 6 步方向预测、最多 6 步预测领先，并保留 12 步恢复历史；本地额外输入延迟为 0。6 步是预测领先上限，不是固定增加的输入延迟。主页面推进与 Worker 补算共用此限制，减少多人持续移动、变向时的无效重算。

联机核心已接入原生帧内调度、受保护同步解释器、TH05 专用 VSync 等价忙等合并、分块内存比较和 PC-98 显存查表。回滚开启且浏览器支持多内存时使用写入记录核心；不支持时使用完整复制回退。画面仅保留最新完整帧，触摸可操作状态随每步模拟更新。

页面显示游戏帧率、每步计算耗时、RTT、输入等待占比和回滚信息，便于区分模拟计算不足与网络等待。开启回滚需要额外计算和内存；慢端仍会限制共同推进速度，中继的网络波动也可能造成停顿。

2026-10-15 的 TH05 忙等、预测限速、原生暂停、Bomb 与幽灵图层等最新修改已完成对应构建或语法解析，尚未完成新一轮游戏、弱设备和异地公网验收。历史公共优化核心在 SM-T500 的无网络短测约 18.64 游戏帧／秒，该数字不代表当前完整版本，也不代表实际联机性能。不能保证低端设备或所有弹幕场景满速。
