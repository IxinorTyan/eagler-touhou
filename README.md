# TH04《东方幻想乡》· DOSBox-X 单机与合作版

当前 `th04-coop-lab` 已采用 DOSBox-X，引擎迁移及后续启动、呈现和多人 HUD 更新已合入本目录。迁移前的 NP21 版本保存在本机同级 `th04-np21/`，用于备份和开发对照；游玩当前版本无需该目录。

游戏使用 DOSBox-X / js-dos `emulators@8.5.2`。单机、本地合作采用 JSPI；联机使用完整 Asyncify 构建，以保存原生执行栈并接入原来的回滚接口。随附运行资源已经构建，原有入口和操作组件继续使用。

## 启动

需要 Python 3 和最新 Chrome / Edge。单机、本地合作需要浏览器支持 WebAssembly JSPI。请运行启动器，通过 HTTP 打开网页。

| 模式 | 启动器 | 地址／端口 |
| --- | --- | --- |
| 原版单机 | `start-solo.bat` | `http://127.0.0.1:9867/solo.html` |
| 本地双人合作 | `start.bat` | `http://127.0.0.1:9867/local.html` |
| 两／三人局域网 | `start-lan.bat` | 9868，伙伴使用窗口显示的局域网地址 |
| 公网联机 | 部署 `lan_server.py` 或 `start-public-tunnel.bat` | 保留原房间、WebRTC 和 WebSocket 接口 |

9867 被占用时本地服务器会寻找后续可用端口，以启动窗口显示的网址为准。手机访问使用局域网服务器。WebSocket 转发模式先运行一次 `install-relay.bat`；临时公网隧道还需要安装 `cloudflared`，并保持局域网服务和隧道窗口同时运行。

详细加入方法见 [局域网试玩说明](LAN-试玩说明.md)，公网／转发部署见 [Relay 说明](README-RELAY.md)。

## 原有操作和玩法

保留汉化／日文选择、原版单机开头及菜单、本地双人、两／三人房间、回滚开关、个人 HUD、独立资源与计分、幽灵和救援、声音模式、手柄、自定义按键与触屏设置。随附中／日文单机和合作四张游戏盘；多人 HUD 的 Power 使用原版小 P 图标，1UP、Bomb 和拾取规则保持原有实现。

默认 P1：方向键、Z 射击、X Bomb、Shift 低速；本地 P2：WASD、J 射击、L Bomb、K 低速。Esc／P 暂停，屏幕按钮亦可操作。键位和触屏布局通过“按键与触控”保存。

触屏保留单指拖动、第二指低速、开火切换、Bomb、双击 Bomb、限速／不限速、灵敏度、判定点、横竖屏独立布局及沉浸显示。独立单机保留跳关与无敌测试工具；单机、本地合作和联机都有“下载故障信息”。

网络使用 `th04-rollback/3` 输入同步协议。房主配置本局设置；各端落座、选机体、准备后开局。回滚由房主在开始前选择。开局会校验各端游戏盘、引擎和适配模块版本，所有玩家须使用同一版资源；DOSBox-X 版与 NP21 备份版不能混用。

磁盘导入／导出接口保留，运行时文件变更写回私有 FAT12 镜像；刷新或重启恢复初始资源。

## 性能与验证

慢设备启动使用临时 `FASTBOOT.BAT`，以较低固定算力完成 BIOS／驱动等待，再在游戏入口前恢复正常配置；联机游戏阶段为 30000 cycles。启动过程中持续让出浏览器任务并更新进度，房间 HTTP 临时失败不会在 5 秒后直接停止仍有活动玩家通道的游戏。2026-10-13 同设置短测，桌面独立运行时启动约 15.2→6.8 秒，USB 平板约 256.5→136.0 秒；不同设备和加载范围的结果不能直接互比。

单机、本地合作使用 DOSBox-X Simple CPU 和自动 cycles，启动页不再显示标准／增强算力选择；游戏时钟保持原版。每次核心提交完整 RGB 画面后直接上传复用纹理并绘制，移除上游额外的刷新回调等待。本地合作可选独立浏览器音乐，减少 FM 音源在模拟线程中的工作；原声仍可保留。联机使用固定 30000 cycles 和虚拟时间；每批推进或回滚追赶完成后，先绘制最新底图，再在同一任务中合成个人 HUD，只向可见画布提交一次。60 Hz 输入／网络调度与游戏步数、WebGL 绘制次数、物理屏幕刷新均为不同指标。

2026-10-13 USB 三星 SM-T500（Chromium 157、Android 12）短测，后台 Worker 单机约 39.8 游戏帧／秒，本地双人持续射击约 31.9。50 帧目标尚未达到，瓶颈仍是 DOSBox-X Simple CPU 的解释执行，不能把 WebGL 绘制次数当作游戏帧率。联机回滚在该设备上更重；这些数字不代表完整通关或所有设备、弹幕场景的表现。

当前浏览器回归覆盖中／日文本地独立输入、Worker／主线程单机、暂停恢复、两／三人 WebSocket 延迟回滚及确认状态一致、日文 WebRTC 确认锁步、客机离线后继续、故障信息下载、完整内存／文件恢复与重放。中／日文 Extra 各完成 12 次暂停恢复、梦月到幻月的切换及幻月继续 600 多游戏帧；这是带 QA 保护及血量加速的回归，不是完整通关成绩。

12 帧完整恢复窗口使用 4 KiB 页面撤销记录，桌面测试占用约 117～118 MiB。浏览器房间回归采用本机多个浏览器上下文；USB 平板与桌面另做过两人 WebSocket 启动及短测，不等于跨网公网或全场景稳定性验证。

游戏中偶发 STOP／紫屏反馈尚未自然复现，不能标为已修复。原游戏将 STOP 和无效指令异常接到同一张警告画面，正常暂停菜单是另一条路径。旧幻月绘制尾部修复仍有效；私有 QA 实例注入无效指令已验证故障下载能保留警告状态及候选中断现场。

如遇黑屏、紫屏或运行停止，请在重启前点击“下载故障信息”，同时保留画面截图；联机时两端均保存。诊断仅在点击时读取并下载到本机，不会自动上传。

开发机的详细记录保存在本地 `reports/`：启动优化、平板性能、小 P／STOP 排查及对应 JSON。该目录不随 Git 发行包发布。迁移前的 NP21 报告属于历史资料，不能作为当前引擎验收证据。

## 更新与仓库内容

更新文件后重启服务，所有玩家关闭旧游戏页、强制刷新并重新建房。启动器直接运行随附资源，不会自动构建游戏盘或引擎。

Git 仓库按 `.gitignore` 的发行白名单管理，包含网页、DOSBox-X JS／MJS／WASM、四张压缩游戏盘、音乐／素材／版本清单、许可证、Python 服务、启动器及公开说明。`tools/`、`patches/`、`baseline/`、`vendor-source/`、`build/`、`reports/`、开发交接及本机配置留在开发机；仅克隆此发行仓库即可游玩，源码重建需要完整本地开发工作区。

## 重建

运行资源随本目录提供，普通游玩不需要 Node.js、NASM 或 Binaryen。以下命令仅用于保留开发文件的本地工作区，固定 npm 来源在 `vendor-source/emulators-8.5.2/`。

修改合作原生补丁后，依次运行 `python tools/build_lab.py --keep-vendor` 和 `python tools/build_lockstep_runtime.py`；后一步先刷新中／日文磁盘声音策略，再重建引擎包装器和版本摘要。只改运行时适配 JS 时也需更新摘要。

完整回滚插桩需要 Binaryen 132，执行 `tools/build_asyncify.ps1 -WasmOpt <wasm-opt.exe路径>`；已有插桩中间文件时，`node tools/build_dosbox_runtime.cjs` 可重建包装器及摘要。编译工具和中间文件放在 `build/`，不使用上游不完整的 Asyncify PC-98 构建。迁移／小 P 完整性审计以本机 `../th04-np21/web/` 为原版对照；该备份仅用于开发审计。

引擎来源和 GPL-2.0 许可见 [DOSBox-X 来源说明](web/vendor/dosbox-x/NOTICE.md) 与 [随附许可证](web/vendor/dosbox-x/LICENSE)。
